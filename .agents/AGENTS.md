
## ?? Mobile-First Priority
- **Always prioritize mobile experience and responsiveness** for all UI components and layouts. Ensure the app feels native and optimized for smaller screens before considering desktop/web layouts.


## Preview Verification
- **Always show the new position/layout in preview**: Whenever the user sends a prompt for modification or alteration of UI/layout, always capture a preview or screenshot of the changes (for instance, using the development server and browser subagent) and present it to the user.

## Strict Implementation Plan Rule
- **Always create an implementation plan before writing the least code**. Never proceed with making code edits without first presenting a detailed implementation plan and waiting for user approval.
